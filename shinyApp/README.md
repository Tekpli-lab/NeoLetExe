# Data Interrogation with ShinyCell

You can interact with the single-cell RNA sequencing data using the following link:

[Explore the Data](https://tekpli.shinyapps.io/shinyappmulti_neoletexe_scrnaseq/)

You can also follow the instructions below to deploy the shinyapp
## Instructions

1. **Install ShinyCell in RStudio**: [ShinyCell Installation Guide](https://github.com/SGDDNB/ShinyCell)
2. **Download the datasets**:
   - All cells: [Download here](https://uio-my.sharepoint.com/:f:/r/personal/xaviert_uio_no/Documents/NeoLetExe_paper/shinyApp/shinyApp_all?csf=1&web=1&e=s3Qp2y)
   - Myeloid cells: [Download here](https://uio-my.sharepoint.com/:f:/r/personal/xaviert_uio_no/Documents/NeoLetExe_paper/shinyApp/shinyApp_Myelo?csf=1&web=1&e=3mygDq)
   - T / NK cells: [Download here](https://uio-my.sharepoint.com/:f:/r/personal/xaviert_uio_no/Documents/NeoLetExe_paper/shinyApp/shinyApp_Tcells?csf=1&web=1&e=BC0QMj)
3. Open the `server.R` file in RStudio.
4. Click the **Run App** button.
5. This should open a web interface that will allow you to interrogate the data interactively.

Enjoy exploring the data!
